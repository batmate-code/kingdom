# Турнир: находки агентов в эвристическом боте

Новая версия бота играет против двух ботов `heuristic` прежней версии, по очереди в каждом кресле (поровну партий в креслах 1, 2, 3), правила — по умолчанию (вход в Город `mixed`, участки за руду). Норма доли побед — 33,3%; ничьи делятся поровну. Сырые результаты не хранятся — воспроизводятся командой ниже.

    npm run sim -- --games N --bots heuristic-<версия>,heuristic,heuristic --seed S   (и так же для кресел 2 и 3)

Версии (веса в packages/bots/src/heuristic/weights.ts):

- **chain** — цепочки престижа зданий: начатая цепочка обещает престиж следующего здания того же типа (Склеп 1 → 3 → 8), `buildingChain = 0.6`.
- **aristo** — Аристократ ценится по цене входа в Город, `aristocratEntryShare = 0.6`.
- **ore** — руда 3 «золота» вместо 4 (бот охотнее меняет её на влияние в Ратуше).
- **co** — chain + ore; **v6** — все три.

| Версия | Партий | Побед (норма 33,3%) | По креслам 1 / 2 / 3 | ПО: версия / соперники |
| ------ | ------ | ------------------- | -------------------- | ---------------------- |
| chain  | 300    | 33.7%               | 31 / 47 / 23         | 11.60 / 11.51          |
| aristo | 300    | 30.3%               | 21 / 50 / 20         | 11.42 / 11.57          |
| ore    | 300    | 35.7%               | 36 / 49 / 23         | 11.75 / 11.42          |
| v6     | 300    | 37.5%               | 36 / 56 / 21         | 11.77 / 11.45          |
| v6     | 900    | 36.6%               | 37 / 48 / 24         | 11.75 / 11.43          |
| ore    | 900    | 38.1%               | 38 / 47 / 29         | 11.80 / 11.47          |
| **co** | 900    | **41.4%**           | 43 / 52 / 29         | 11.86 / 11.41          |

Первый круг — seed 30000…, 100 партий на кресло; второй — seed 31000…, 300 на кресло. Погрешность доли побед: ±2,7% при 300 партиях, ±1,6% при 900.

**Итог:** co (цепочки зданий + руда 3) — новые веса по умолчанию (+8 п. п. к норме). Аристократ по цене входа ослабляет бота (вес оставлен флагом `heuristic-aristo`). Прежняя версия — `heuristic-v5`.

Важно: статистика с новым ботом (доли персонажей, локаций, остатки ресурсов) несравнима с прежними отчётами — базу нужно снять заново.
