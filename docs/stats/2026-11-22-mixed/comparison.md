# Вход в Город: только кровь против «1 кровь + подорожания золотом»

100 партий на вариант, 3 эвристических бота, seed 20000…, остальные правила — по умолчанию.

- **new** — текущие правила: вход только кровью, растёт 1 → 2 → 3.
- **mixed** — эксперимент автора 22.11 (`cityEntryResource=mixed`): 1 кровь, каждое подорожание +1 золото (до 1 кр + 2 зол).
- Для справки — **old** из docs/stats/2026-11-23b: вход только золотом.

## Выводы

- **Сбросы на содержании** снизились с 4.16 до 3.25 — почти до прежнего уровня (2.83). Крови на вход уходит вдвое меньше (5.1 → 2.7).
- **Золото** копится меньше: остаток 4.2 → 3.8, у победителя 4.0 → 3.0. Около 2 золота за партию ушло на вход.
- **Город** почти не потерял посещаемости (8.8 → 8.3 размещений; при входе за золото было 6.3).
- **Средние ПО** не изменились (11.3 → 11.4).
- Что ухудшилось: Цитадель Города строится реже (20% → 11% партий), двойных участков в Городе чуть меньше — золото теперь нужно и на вход, и на доплату.
- Перекос по креслам остался: второе место выигрывает ~45%, третье — 17–22%. Это не связано с ценой входа, проверить отдельно.
