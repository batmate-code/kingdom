# Персонажи: 200 партий, 3 × «Умный бот» (heuristic), все 30 карт — 23.11

Команда: `npm run sim -- --games 200 --bot heuristic --players 3 --seed 1 --rule disabledCharacters=false`.
Отчёт — report.md (таблица «Персонажи»), сырые данные — stats.json.

Норма побед — 35 % (победители / игроки, с ничьими). Две метрики:

- «Взят победителем» — доля драфтов карты, сделанных будущим победителем (сотни случаев у частых карт);
- «Побед у держателя» — карта у игрока в конце партии (у редких карт 10–20 случаев — шум).

Погрешность у частых карт около ±5–7 п. п.

## Сильные

| Карта       | Взят победителем | Побед у держателя | Очерёдность пика  |
| ----------- | ---------------- | ----------------- | ----------------- |
| Меценат     | 49 %             | 48 %              | 1,5               |
| Манипулятор | 45 %             | 43 %              | 1,2               |
| Комиссар    | 47 %             | 38 %              | 2,8 (берут редко) |

Меценат и Манипулятор — карты влияния: прямо двигают треки, то есть ПО. Их и убирали из колоды прогонов.

## Слабые или ловушки (их охотно берут, но выигрывают реже нормы)

| Карта        | Взят победителем | Побед у держателя | Очерёдность пика |
| ------------ | ---------------- | ----------------- | ---------------- |
| Рудокоп      | 23 %             | 19 %              | 1,3              |
| Ренегат      | 26 %             | 18 %              | 2,4              |
| Шантажист    | 26 %             | 29 %              | 1,5              |
| Рудный барон | 27 %             | 26 %              | 1,9              |
| Кровосос     | 29 %             | 25 %              | 2,2              |
| Каменщик     | 24 %             | 30 %              | 2,8              |

Рудокоп — главная ловушка: бот берёт его почти первым, а победитель — реже всех. Руда, видимо, переоценена ботом или
не конвертируется в очки.

## Бот не умеет играть (берёт меньше чем в 1 случае из 5)

Диверсант (0 %), Могильщик (3 %), Интриган (4 %), Лицемер (4 %), Ночной охотник (6 %), Безумец (6 %),
Лазутчик (19 %). Их силу прогон оценить не может: это слепое пятно эвристики, а не обязательно слабость карты.

## Раунд пика

Средний раунд пика у всех карт 3,3–3,7, распределение по раундам ровное: в какой раунд карта попадёт на драфт,
решает колода, а не выбор. Показательнее очерёдность пика внутри раунда (1 — берут первой).

## Замечания к статистике

- Сброс на содержании больше 100 % у редких карт: в знаменатель идут назначения, а в числитель попадают и другие
  сбросы этой карты — колонка для редких карт неточна.
- У Диверсанта 0 пиков, но «держат к концу 0,10»: вероятно, карта приходит к игрокам мимо драфта (Таверна) —
  стоит проверить сбор статистики.
- Победы по креслам 34 / 42 / 24 % — перекос 3-го кресла сохраняется.
