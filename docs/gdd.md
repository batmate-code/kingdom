# Вампирская игра — диздок (актуальные правила)

Состояние на 25.11.2026. Это сводка правил **в том виде, в каком они сейчас работают в движке по умолчанию**.
Старые документы (`docs/rules.md`, `docs/author-answers-*.md`) — история решений: этот файл их заменяет как
справка, но не отменяет. Все числа ниже берутся в коде из `packages/data` — при расхождении прав код.

## 1. Суть игры

Настольная стратегия на 2–4 игроков (базово — 3) о вампирских кланах, делящих три региона: **Лес**, **Долину** и
**Город**. Партия — 6 раундов. В каждом раунде игроки:

1. драфтом набирают пару «персонаж + профессия» и улучшают ею одного из трёх своих рабочих;
2. по очереди выставляют рабочих в локации регионов — получают ресурсы, меняют их, строят здания;
3. в конце раунда в каждом регионе проходит бой с закрытыми жетонами; победитель получает влияние.

Побеждает тот, у кого больше **победных очков (ПО)**. ПО приносят: отметки на треке престижа (здания,
персонажи), отметки на треках влияния регионов, жетоны первенства и Шпили.

Ключевые идеи дизайна:

- **Рабочих мало (3), слотов в локациях — по два.** Первый слот «держит регион» в бою, второй — вспомогательный.
  Вытеснение из первого слота — главная форма прямого конфликта.
- **Персонаж — бонус к каждому размещению** этого рабочего, но стоит крови каждый раунд (содержание).
- **Влияние идёт в обе стороны** (обратные треки): вверху — ПО и Шпиль, внизу (до −4) — ресурсы, право
  стройки, постоянная сила и Обелиск.

## 2. Компоненты и параметры

| Параметр                 | Значение                                                                                |
| ------------------------ | --------------------------------------------------------------------------------------- |
| Игроков                  | 2–4 (параметры игры одинаковые, как для троих)                                          |
| Раундов                  | 6                                                                                       |
| Рабочих у игрока         | 3 (все без улучшения в начале)                                                          |
| Старт                    | 2 золота, 1 кровь                                                                       |
| Ресурсы                  | золото, кровь, руда, компромат                                                          |
| Регионы                  | Лес, Долина, Город — бои в этом порядке                                                 |
| Локации                  | 10: Лес 3, Долина 3, Город 4; у каждой 2 слота                                          |
| Жетоны профессий локаций | 10 — по 2 каждой профессии; задают «требование для вытеснения»                          |
| Профессии                | 5: Страж, Палач, Архитектор, Аристократ, Шпион; запас не ограничен                      |
| Персонажи                | колода 34 карты; по умолчанию Манипулятор и Меценат убраны, колода добирается повторами |
| Жетоны боя               | у каждого: Атака, Защита, Резня, Доминация, Отступление — по 1, Приманка — 2            |
| Жетоны силы              | временные (+1 к силе в регионе), снимаются в конце раунда                               |
| Участки                  | по 6 в каждом регионе + звезда региона (места под Шпиль/Обелиск)                        |
| Госпиталь                | один общий                                                                              |

Первый игрок 1-го раунда — Игрок 1; в конце каждого раунда первый игрок переходит по часовой стрелке.

## 3. Структура раунда

1. **Подготовка.**
   - Жетоны профессий локаций раскладываются случайно в 1-м раунде и **заново в начале 3-го и 5-го** (когда
     жетоны боя вернулись в руку). Раскладка открытая.
   - Выкладываются 5 случайных персонажей и 5 профессий (по одной каждой).
2. **Драфт.** Круг 1 начинает **последний** игрок (тот, кто ходит последним в этом раунде), дальше против
   часовой — к первому; каждый берёт персонажа **или** профессию. Круг 2 — в обратном порядке, каждый берёт
   недостающее. Остаток (при 3 игроках — 2 персонажа и 2 профессии) — пул Таверны.
3. **Улучшение** (по очереди с первого игрока, открыто). Пару назначают на рабочего без улучшения или заменяют
   ею имеющуюся (за старую пару — отступные), либо сразу сбрасывают за отступные (профессия пропадает тоже).
4. **Размещение.** По одному рабочему по кругу с первого игрока, пока все не выставлены или не спасовали. Пас
   окончательный. Рабочий, вернувшийся в запас посреди раунда, может быть выставлен снова.
5. **Бои:** Лес → Долина → Город (перед ними — перемещения Шпионов).
6. **Конец раунда.**
   - Все рабочие (с поля и из госпиталя) возвращаются в запас.
   - **Содержание:** за каждого улучшенного рабочего платится кровь по карте персонажа (−1, если рабочий был в
     госпитале; не ниже 0). Игрок сам выбирает, кого оплатить, а кого сбросить за отступные.
   - Снимаются жетоны силы, замки, жетон Комиссариата.
   - Копилка Логова +1 руда, если второй слот Логова в этом раунде никто не занимал.
   - После 2-го, 4-го и 6-го раунда сыгранные жетоны боя возвращаются в руку.
   - Первый игрок переходит по часовой стрелке.

## 4. Размещение, вытеснение, госпиталь

- **Порядок эффектов при размещении:** персонаж → действие локации → профессия.
- **Первый слот** — любой рабочий, если свободен. **Второй слот** можно занять, даже если первый свободен.
- **Вытеснение.** Если профессия рабочего, которого ставят во второй слот, совпадает с жетоном профессии
  локации, а первый слот занят, — рабочий из первого слота может быть отправлен в госпиталь (по желанию).
  Вытесняющий выполняет действие **второго** слота, но переходит в первый (и считается в бою). Второй слот
  закрывается замком до конца раунда. Своего рабочего вытеснить можно.
- **Компенсация:** владелец вытесненного получает 1 компромат. Действие вытесненного не отменяется.
- **Страж** не может быть вытеснен (и блокирует обычное вытеснение из слота, где стоит).
- Нельзя вытеснить или убрать с поля рабочего, который ещё не доиграл свой ход.
- **Госпиталь** — общий. Рабочие в нём в бою не участвуют (их силу может забрать жетон Комиссариата).

## 5. Вход в Город

Плата, когда игрок в свой ход выставляет рабочего из запаса в локацию Города (и при Комиссаре):

- базово **1 кровь**;
- когда любой игрок впервые достигает 5 влияния в Лесу — вход дорожает на **+1 золото**; так же для Долины;
  максимум 1 кровь + 2 золота;
- **Аристократ** входит бесплатно; перемещения Шпиона и Отступления бесплатны.

## 6. Локации

«Золото/кровь» — в любой комбинации. Подсказка по ценности слотов — `docs/balance/locations-model.md`.

### Лес

| Локация      | Слот 1    | Слот 2                                                             |
| ------------ | --------- | ------------------------------------------------------------------ |
| Рудник       | +3 золота | +2 золота                                                          |
| Ведьмин круг | +3 крови  | +2 крови                                                           |
| Логово       | +1 руда   | забрать всю руду из копилки и по желанию один раз 3 крови → 1 руда |

### Долина

| Локация | Слот 1                                                                                                                                                                                       | Слот 2                                |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| Месса   | один обмен 2 → 6: золото → кровь или кровь → золото                                                                                                                                          | 1 руда → 2 жетона силы в любой регион |
| Рынок   | 2 золота/крови → 2 руды                                                                                                                                                                      | +1 компромат, +1 золото               |
| Таверна | заменить пару своего рабочего на пару из пула Таверны (за старую — отступные; рабочий без улучшения берёт пару бесплатно); новый персонаж в этом размещении не срабатывает; можно отказаться | +1 золото, +1 кровь                   |

### Город

| Локация     | Слот 1                                                                                                                                                                 | Слот 2                                                                                    |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Канцелярия  | до 2 действий (можно повторять и смешивать): 1 компромат → 3 золота/крови; 2 компромата → 1 руда + 1 золото; 1 компромат → право стройки (не больше одного, последним) | 1 компромат → право стройки                                                               |
| Подполье    | бесплатно выполнить действие любого слота любой локации Леса или Долины, даже занятого                                                                                 | 3 компромата → 1 влияние или 5 компроматов → 2 влияния (2 можно разделить на два региона) |
| Комиссариат | взять жетон Комиссариата и выбрать регион: в бою там +1 сила владельцу за каждого рабочего в госпитале (любого игрока); жетон — присутствие в бою и без своих рабочих  | 1 компромат → вернуть своего рабочего из госпиталя в запас                                |
| Ратуша      | 1 руда → 1 влияние или 3 руды → 2 влияния                                                                                                                              | 2 руды → 1 влияние или 4 руды → 2 влияния                                                 |

Влияние Ратуши и Подполья — в любой регион; обмен на 2 влияния можно разделить 1 + 1 между регионами.
**Право стройки** Канцелярии — сразу, в любом регионе, на любой свободный участок, по полной цене; купить
его можно, только если есть что построить.

Копирование Подпольем и эффект Безумца не считаются посещением (не срабатывают Лавка и Цитадель Города).

## 7. Профессии

Профессия всегда в паре с персонажем: сброс или неуплата уносит обоих.

| Профессия  | Эффект                                                                                                                                                                                                                                                                       |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Страж      | Нельзя вытеснить. Сила в бою 2.                                                                                                                                                                                                                                              |
| Палач      | При размещении прямо в первый слот (или переходе туда вытеснением) может вытеснить чужого рабочего из первого или второго слота другой локации своего региона; совпадение профессии не нужно. Владелец вытесненного и сам Палач получают по 1 компромату. Замок не ставится. |
| Архитектор | При размещении (в любой слот) может построить здание на свободном участке у своей локации по полной цене.                                                                                                                                                                    |
| Аристократ | Не платит за вход в Город.                                                                                                                                                                                                                                                   |
| Шпион      | Сила в бою 2. Перед боями может перейти в любой свободный слот своего или другого региона без действия.                                                                                                                                                                      |

## 9. Бой

### Участие и сила

- В бою региона участвует игрок, у которого там есть любой рабочий (в любом слоте), или владелец жетона
  Комиссариата этого региона.
- **Сила** = рабочие в **первых** слотах и у звезды (1; Страж и Шпион — 2) + свои жетоны силы + Склепы (+1 за
  каждого своего рабочего в локациях, соседних с твоим Склепом) + постоянная сила отметки −3 + жетон
  Комиссариата (+1 за рабочего в госпитале) + жетон боя.
- Победитель — максимальная сила; при равенстве — больше участвующих рабочих; иначе победителя нет.

### Перед боями

Шпионы по очереди с первого игрока могут перейти в любой свободный слот своего или другого региона (без
действия, без платы за вход).

### Жетоны боя

Каждый участник, у кого есть жетоны в руке, кладёт один в закрытую; вскрытие одновременное. Сыгранные уходят в
сброс; весь набор возвращается в руку после 2-го, 4-го и 6-го раунда.

| Жетон       | Кол-во | Эффект                                                                                                                                                                                         |
| ----------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Атака       | 1      | +1 к силе                                                                                                                                                                                      |
| Резня       | 1      | +2 к силе                                                                                                                                                                                      |
| Защита      | 1      | Отменяет Резню каждого соперника и тогда даёт +1 к силе; иначе 0                                                                                                                               |
| Доминация   | 1      | При победе +1 влияние сверх награды; отменяет Отступление соперника. Нельзя играть, если в регионе нет соперников                                                                              |
| Отступление | 1      | Проигрыш боя; все свои рабочие региона переходят к звезде региона, где боя ещё не было (там участвуют). В Городе — просто проигрыш. Можно добровольно потерять до 2 влияния (спуск, раздел 10) |
| Приманка    | 2      | Без эффекта (блеф). Можно добровольно потерять до 1 влияния                                                                                                                                    |

Треугольник: Атака бьёт Защиту, Защита — Резню, Резня — Атаку.

### Награда победителю

+1 влияние в регионе и на выбор: ещё +1 влияние **или** право построить здание в этом регионе (сразу, на
свободном участке, по полной цене). Доминация — ещё +1 влияние. Владелец Шпиля региона может вместо всей
награды взять **1 постоянное ПО**.

## 10. Влияние: треки вверх и вниз

Влияние на каждом треке — от **−4** до максимума региона (Лес и Долина 6, Город 8).

| Трек   | Максимум | ПО на отметках | Порог Шпиля | Бонусы позиций (каждому игроку один раз за партию)                |
| ------ | -------- | -------------- | ----------- | ----------------------------------------------------------------- |
| Лес    | 6        | 3, 6           | 4           | на 2 — +2 золота; на 5 — вход в Город дорожает (один раз на всех) |
| Долина | 6        | 3, 6           | 4           | на 2 — +2 крови; на 5 — вход в Город дорожает                     |
| Город  | 8        | 3, 5, 8        | 6           | на 2, 4 и 7 — по +1 руде                                          |

- **ПО за отметки** считаются по позиции в конце игры (влияние можно потерять).
- **Жетон первенства:** первый, кто дошёл до максимума трека, получает 1 ПО навсегда.

### Спуск вниз

Влияние опускают: Приманка (до 1) и Отступление (до 2) — по выбору игрока при выборе жетона; Ренегат (−1);
Шантажист (у соперника); Манипулятор. Обычное поражение влияние не снимает. Ниже −4 опуститься нельзя.
Отрицательное влияние ПО не даёт.

| Отметка | Награда                                           | Как часто                                                         |
| ------- | ------------------------------------------------- | ----------------------------------------------------------------- |
| −1      | +1 руда                                           | каждый раз, когда влияние опускается до −1 или ниже с уровня выше |
| −2      | право стройки сразу в этом регионе по полной цене | каждый раз                                                        |
| −3      | постоянный +1 к силе в боях этого региона         | один раз за партию (игрок + регион)                               |
| −4      | право построить Обелиск                           | один раз за партию                                                |

Перескочил несколько отметок — получаешь все.

## 11. Здания

Не больше 3 зданий каждого типа у игрока. Престиж начисляется при постройке по номеру здания этого типа.
Здание на двойном участке соседствует с **обеими** локациями.

| Здание         | Цена              | Эффект (для соседних локаций)                                          | Престиж 1-е / 2-е / 3-е |
| -------------- | ----------------- | ---------------------------------------------------------------------- | ----------------------- |
| Склеп          | 2 золота          | +1 к силе в бою региона за каждого своего рабочего в соседних локациях | 1 / 3 / 8               |
| Аббатство      | 4 золота          | +2 крови владельцу при каждом вытеснении рабочего из соседней локации  | 4 / 4 / 4               |
| Торговая лавка | 3 золота + 1 руда | +1 золото владельцу, когда чужой рабочий приходит в соседнюю локацию   | 5 / 2 / 5               |

**Участки.** Лес и Долина: по 3 одиночных и 3 двойных (каждая пара локаций региона); доплата за двойной —
**+1 руда**. Город: 6 участков, все двойные (каждая пара локаций), без доплаты.

### Звезда региона: Шпиль и Обелиск

На звезде каждого региона — **2 места при 3–4 игроках** (1 при двух); кто построил первым.

|           | Шпиль                                                                   | Обелиск                                                                                                               |
| --------- | ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Условие   | влияние ≥ 4 (Город ≥ 6)                                                 | влияние на −4 (право отметки −4)                                                                                      |
| Цена      | 6 золота + 2 руды                                                       | 2 руды + 2 компромата                                                                                                 |
| Престиж   | 10                                                                      | 5                                                                                                                     |
| На игрока | 1                                                                       | 1                                                                                                                     |
| Эффект    | победа в бою этого региона — можно взять 1 постоянное ПО вместо награды | при постройке влияние строящего в регионе становится 0; когда соперник выигрывает бой региона — владелец +1 компромат |

Строятся теми же способами, что и обычные здания (право стройки Канцелярии, награда за бой, Архитектор,
отметка −2, Подрядчик). Рабочие у звезды (после Отступления) участвуют в бою, но не стоят в локации.

## 12. Конец игры и подсчёт

После 6-го раунда (с оплатой содержания):

1. Престиж за персонажей, оставшихся у рабочих (1–4 по содержанию).
2. **ПО** = отметки трека престижа + отметки треков влияния по финальным позициям + жетоны первенства + ПО
   Шпилей.
3. **Трек престижа** до 58; ПО на отметках 3, 6, 10, 15, 20, 26, 33, 40, 48, 53, 58.
4. **Тай-брейк:** ПО → престиж → владелец Шпиля/Цитадели Города; иначе ничья.

## 13. Переключатели (не по умолчанию)

Правила-эксперименты, включаемые при старте партии или в симуляторе (`--rule ключ=значение`). Полный список —
`RuleToggles` в `packages/core/src/config.ts`. Важные:

| Переключатель            | По умолчанию                         | Альтернатива                                                                                                                                                                                            |
| ------------------------ | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `influenceModel`         | `reverse` (раздел 10–11)             | `classic`: треки от 0, Цитадель вместо Шпиля, одна на регион, с бонусами региона (Лес +2 силы в боях Леса; Долина −1 к содержанию; Город +1 компромат за чужое посещение Города); без Обелиска и спуска |
| `disabledCharacters`     | `true` (без Манипулятора и Мецената) | `false` — вся колода                                                                                                                                                                                    |
| `combatTokenSet`         | `six` (раздел 9)                     | `base`: 10 жетонов (5 Приманок), возврат после 3-го раунда                                                                                                                                              |
| `draftStart`             | `last`                               | `first` — драфт с первого игрока                                                                                                                                                                        |
| `professionTokensReroll` | `true`                               | `false` — профессии локаций раздаются один раз                                                                                                                                                          |
| `draftSize`              | `fixed` (5 + 5)                      | `players` — игроков + 1 персонажей и случайные профессии из пула                                                                                                                                        |
| `effectOrder`            | `fixed`                              | `free` — игрок сам выбирает порядок эффектов размещения                                                                                                                                                 |
