# Онлайн: чеклист ручной проверки

Обозначения: **Х** — хост (держит партию), **Г** — гость (открыл ссылку-приглашение).

## Подготовка

- Между разными устройствами: `npm run online` — сам соберёт игру, поднимет сервер и туннель и откроет https-адрес; связь идёт через этот сервер. Адрес вида `http://192.168.…` из локальной сети не подойдёт (браузер даёт шифрование и ключи только на https или localhost).
- До публикации — блок A на одном компьютере.
- Х: экран настройки → в кресле «Гость по ссылке» → «Начать партию» → в шапке кнопка «Игрок N — пригласить» копирует ссылку.

## A. Один компьютер (можно сейчас, `npm run dev`)

1. [ ] Ссылку открыть во второй вкладке или другом браузере (Chrome + Edge): за 1–3 с у Г «Онлайн: связь с хостом есть», у Х «Игрок N: в сети».
2. [ ] Г видит только свою руку и свои жетоны; ходит только в свою очередь; в чужой ход действий нет.
3. [ ] Ход Г появляется у Х (журнал, поле), ход Х и ботов — у Г.
4. [ ] Бой: Г выбирает жетон в окне; чужие жетоны у Г не видны до вскрытия; окно итогов боя у обоих.
5. [ ] Х обновляет страницу (F5): у Г «Связь потеряна — переподключение…», через ~2 с снова онлайн; партия у Х на месте.
6. [ ] Г обновляет страницу: возвращается в своё кресло, партия продолжается.
7. [ ] Г закрывает вкладку: у Х через ~7 с «не в сети».
8. [ ] Ссылку открыть, когда вкладка Х закрыта: «Подключение…», через 15 с подсказка «Хост не отвечает…»; открыть Х — Г подключается сам.
9. [ ] Вторая вкладка Х с той же партией: в шапке «Комнату держит другая вкладка этого браузера».
10. [ ] Испорченная ссылка (изменить символ в `key=`): «Неверная ссылка-приглашение».
11. [ ] «Отменить ход» у Х и Г неактивна.
12. [ ] Две ссылки (два кресла «Гость по ссылке»): каждый гость в своём кресле, оба ходят.
13. [ ] Партия доигрывается до конца, окно итогов у обоих.

## B. Разные сети (после публикации на https)

1. [ ] Х дома (Wi-Fi), Г на мобильном интернете (Wi-Fi на телефоне выключен) — подключение, время до «Онлайн», задержка ходов.
2. [ ] Х и Г в разных квартирах (разные Wi-Fi).
3. [ ] Г в рабочей сети или под VPN. Если «Хост не отвечает» и не проходит — записать сеть: нужен TURN-сервер.
4. [ ] Х обновляет страницу посреди хода Г.
5. [ ] Ноутбук Г засыпает на 1–2 минуты и просыпается: возвращается ли связь сама.
6. [ ] Г обновляет страницу 3–4 раза подряд: нет ли «вечного подключения».
7. [ ] Два гостя из разных сетей; один отключается — второй продолжает.
8. [ ] Браузер с блокировкой WebRTC (расширение приватности, Brave со строгими настройками): понятна ли подсказка.

## Что записать при сбое

Сеть Х и Г (дом / мобильный / рабочая / VPN), браузеры, шаг из списка, что видно в шапке у обоих, время до сбоя; по возможности — скриншот консоли (F12) у обоих.
