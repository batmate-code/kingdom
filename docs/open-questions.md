# Открытые вопросы по правилам

Сюда попадает всё, что в правилах неясно или противоречиво. В коде каждый вопрос — переключатель в `GameConfig` с комментарием `// OQ-<номер>`. Закрытые вопросы переносятся в docs/author-answers-*.md.

Формат записи:

```
## OQ-N. Краткая суть
- Пункт правил: …
- Вопрос: …
- Варианты: A) … B) …
- Сейчас в config: `имяПереключателя = …` (вариант A)
- Статус: открыт
```
