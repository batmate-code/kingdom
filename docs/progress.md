## Этап 0 — скелет

Сделано:

- npm workspaces из пяти пакетов: data, core, bots, sim, web. Пакеты экспортируют исходники TypeScript.
- TypeScript strict (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`), Vitest, ESLint, Prettier.
- ESLint проверяет границы пакетов и запрещает `Math.random` и `Date.now` в data/core/bots.
- В каждом пакете дымовой тест, подтверждающий, что зависимости подключены. В web — заглушка Vite + React.
- CLAUDE.md, агенты implementer, reviewer и rules-auditor, docs/open-questions.md.
- Ответы автора собраны в docs/author-answers-2026-11-21.md, изображения компонентов — в docs/images/.
